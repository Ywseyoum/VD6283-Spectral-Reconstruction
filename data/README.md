# Data

This directory is reserved for public-safe sample data or links to external datasets used by the project.

The project worked with two distinct kinds of data:

1. **Synthetic/modeling data** derived from a larger fluorescence reference collection (including PhotochemCAD spectra) and simulated VD6283 channel responses.
2. **Experimental data** collected from lab fluorescence measurements and corresponding sensor readings.

Raw internship or laboratory datasets should not be uploaded here unless public release is clearly permitted. A small de-identified or synthetic example dataset can be added later to demonstrate the workflow without exposing restricted research materials.
