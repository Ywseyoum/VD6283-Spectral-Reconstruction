# MATLAB Source

The public-safe MATLAB reconstruction framework is available in [`framework/`](framework/).

The framework includes the project’s reusable computational workflow for:

- flexible spectral and detector-data import
- wavelength alignment and preprocessing
- synthetic detector-response generation through numerical integration
- real detector-data matching
- normalization and feature handling
- PCA, PLS, ridge, ensemble, and neural-network reconstruction approaches
- cross-validation and model ranking
- spectral-error metrics and diagnostic plots
- trained-model and results export

Start with [`framework/README.md`](framework/README.md) or run `framework/START_HERE.m` in MATLAB.

Raw internship measurements and internal research documents are intentionally not included in this public repository.
